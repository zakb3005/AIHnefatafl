# 🧠 AI Hnefatafl

This project implements an AI-driven version of *Hnefatafl* (Tablut ruleset) using Python. It simulates the classic asymmetric board game where one player controls a king and defenders trying to escape, while the other controls attackers trying to capture the king. Both sides are controlled by agents using adversarial search strategies such as Minimax.

The environment is built using the [Gymnasium](https://gymnasium.farama.org/) framework and supports turn-based gameplay, legal move enforcement, capture mechanics, and win/loss conditions.
